# Reflection

## What I Learned

This laboratory activity helped me understand the difference between virtual machines and containers. I learned that virtual machines include a complete operating system, while containers share the host operating system kernel and are more lightweight.

I also learned how Docker is used to create, run, and manage containers. Docker makes it easier to package an application together with its dependencies so that it can run consistently in different environments.

## My Experience

While doing the activity, I learned that containers can be started and managed more quickly compared to virtual machines. I also became more familiar with basic Docker commands and how they are used when deploying applications.

## Conclusion

Overall, this activity improved my understanding of virtualization, containerization, and Docker. It showed me how containers can be useful for developing and deploying applications in cloud-native environments.
