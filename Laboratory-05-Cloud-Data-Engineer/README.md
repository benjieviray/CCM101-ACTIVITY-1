# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud storage concepts and object storage using MinIO. The mission involves deploying MinIO using Docker, accessing the MinIO web console, creating a bucket, and uploading a test object.

## Objectives

- Differentiate Block Storage, File Storage, and Object Storage.
- Deploy an S3-compatible MinIO object storage service using Docker.
- Access the MinIO web console through the appropriate port.
- Create a bucket named `client-photos`.
- Upload a test file to the bucket.
- Document the deployment and learning experience using Markdown.

## Tools Used

- KillerCoda Ubuntu 24.04
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Understanding different cloud storage types
- Deploying containerized applications using Docker
- Using environment variables in Docker
- Accessing services through forwarded ports
- Creating and managing an object storage bucket
- Documenting cloud computing activities using Markdown
